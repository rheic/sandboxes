# Терминальная панель

`rsbx tui` открывает read-only представление локальных sandbox в терминале. Для работы с локальным daemon используется Go SDK.

```sh
rsbx tui
```

Перемещайтесь стрелками или `j`/`k`, обновляйте список клавишей `r`, выходите через `q` или `Esc`. Панель не запускает, не останавливает, не удаляет sandbox и не подключает к нему терминал. Для изменений используйте соответствующую команду CLI.

Если панель не подключается, проверьте выбранный socket daemon через `rsbx --socket PATH tui` и убедитесь, что daemon запущен. См. [Решение проблем](troubleshooting.md).
