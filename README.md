# Rheic documentation

Bilingual documentation for Rheic local sandboxes, published at <https://rheic.github.io/sandboxes/>.

## Preview locally

```sh
./dev.sh
```

The preview listens on `http://127.0.0.1:8000`. To build both languages with strict warnings:

```sh
./dev.sh check
```

The build uses the pinned dependencies in `requirements.txt`.
